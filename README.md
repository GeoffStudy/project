# To-Do-List App

A simple browser-based to-do list app built with HTML, CSS, and JavaScript.

## Purpose
This app helps users write down tasks, mark them as complete, delete them, and keep their list saved in the browser using localStorage.

## Features
- Add new tasks from an input field
- Mark tasks as complete by clicking the task text
- Delete tasks from the list
- Tasks are saved automatically in localStorage
- Saved tasks are restored when the page reloads
- Clean, responsive styling for a simple and pleasant user experience

## How to Use
1. Open the app in a browser.
2. Type a task in the input box.
3. Click the Add button or press Enter.
4. Click a task to mark it complete.
5. Click Delete to remove a task.

## Files
- `index.html` – app structure
- `style.css` – styling and visual polish
- `app.js` – task logic and localStorage behavior
